### Program Description

This Higher National Diploma focuses on cloud infrastructure, virtualization, system administration, and basic networking configurations. It prepares students to design, deploy, and manage secure and scalable cloud networking environments.

---

### Core Areas of Focus & Competencies

* **Cloud Infrastructure Basics**: Learn basic cloud computing models (IaaS, PaaS, SaaS), cloud storage, and virtual resource deployment.
* **Networking Fundamentals**: Core networking architectures, routing protocols, subnetting, IP configuration, and server administration.
* **System Troubleshooting**: Identifying hardware and software performance issues, configuring secure connection paths, and analyzing server logs.
* **Modern Networking Technologies**: Hands-on learning in SLT-Mobitel NEBULA environments focusing on reliable connectivity, data routing, and infrastructure scaling.
