### Overview

These projects focus on core software engineering fundamentals, demonstrating clean code practices, logic formulation, and object-oriented programming (OOP) architectures. Using Python and Java, I built terminal-based systems and solved algorithmic problems with appropriate data structures.

---

### Core Principles & Architecture

#### 1. Object-Oriented Design (OOP)
* **Encapsulation**: Styled classes with private attributes, exposing access through getter and setter interfaces to protect data state.
* **Inheritance**: Engineered hierarchical class structures to share core behaviors, reducing duplicate code.
* **Polymorphism**: Overrode and overloaded methods to handle dynamic object types at runtime (e.g., handling generic transactions or user actions).
* **Abstraction**: Utilized abstract classes and interfaces in Java to construct standard system blueprints.

#### 2. Algorithms & Data Structures
* Implemented sorting (e.g., Bubble Sort, Quick Sort) and searching (e.g., Binary Search, Linear Search) algorithms to solve lookup and ordering challenges.
* Leveraged primitive and collection data structures including:
  * **Arrays & Lists** for sequential data storage.
  * **Stacks & Queues** to handle order-specific data processing.
* Built basic automation scripts and data parser systems to process, clean, and convert user inputs in console applications.

#### 3. Debugging & Code Reliability
* Conducted detailed code tracing and modular debugging using modern debugger tools (VS Code Debugger).
* Handled edge cases and program exceptions (e.g., null pointers, index-out-of-bounds, invalid formats) to ensure application stability under unexpected user inputs.
