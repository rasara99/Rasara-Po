### Overview

As part of my academic coursework and personal growth, I designed and developed several responsive web applications. The goal was to build user-friendly, accessible interfaces that adapt seamlessly to desktop and mobile platforms while integrating lightweight backend logic.

---

### Core Highlights & Deliverables

#### 1. Responsive & User-Friendly Layouts
* Designed and built clean, custom layouts using HTML5, CSS3, and modern CSS layout techniques (Flexbox, Grid).
* Ensured mobile-first responsiveness so that all components stack and scale appropriately on screen sizes from mobile to wide desktops.
* Applied professional typography, subtle gradients, and smooth transition effects to elevate visual aesthetics.

#### 2. Interactive Front-Ends with React.js
* Developed interactive user interfaces using React.js, managing state cleanly for real-time updates.
* Leveraged components to create modular, reusable code structures.
* Implemented dynamic content rendering to change states and load views dynamically without full page reloads.

#### 3. Backend Integration with Node.js
* Set up simple server-side logic and API routes using Node.js and Express.
* Connected frontend forms to server routes to simulate database fetches, form submissions, and basic server-side calculations.
* Structured basic middleware for request handling and input validation.

#### 4. UI/UX Refinement
* Prioritized user flows and navigation simplicity to maximize usability.
* Refined color contrast, interactive states (hover, active, focus), and input fields to comply with standard accessibility guidelines.
